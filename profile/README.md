# MEW Monster (뮤몬스터)

Software for music academies, product teams and AI education.
음악학원과 제품 팀, AI 교육을 위한 소프트웨어를 만듭니다.

## Products

- **Monster SaaS**: operations for multi-branch music academies. Lessons, attendance and make-up lessons, practice rooms, revenue and teacher settlement.
- **DevOps**: one workspace per project for specs, user flows, QA test design, issues, schedules and API health.
- **API Checker (API 확인소)**: shows which of 10,086 Korean public APIs actually return data.

## Education projects

- **Modu AI Lounge (모두의 AI 라운지)**: AI classes at five Gyeonggi-province media centers, in one public site.
- **AI Lab Lectures (AI 실험실 강의)**: beginner courses from the first prompt to public data and automation.

## Built with Claude

Monster SaaS and DevOps are connected through the Claude API. Claude writes drafts, such as specs, QA cases and weekly summaries, and a person approves each one. Prompts get counts and totals, never personal data.
